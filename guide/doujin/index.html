同人誌・グッズの在庫と確定申告

更新日：2026年10月24日

同人誌やグッズを作って売っていると、「印刷代を全部その年の経費にしていいの？」と迷います。答えは、売れた分だけがその年の経費。売れ残りは「在庫」として翌年に持ち越します。

売上原価のしくみ

売上原価 ＝ 年はじめの在庫 ＋ 今年の製作費（仕入）− 年末の在庫

例：新刊を150部、印刷代 66,000円で作り、年末に38部残ったら

  • 1部あたりの原価：66,000円 ÷ 150部 ＝ 440円
  • 年末の在庫：440円 × 38部 ＝ 16,720円
  • その年の売上原価（経費）：66,000円 − 16,720円 ＝ 49,280円

翌年、残りの38部が売れたら、16,720円はその年の売上原価になります。

在庫・売上原価 計算ツールで計算する

年末の在庫の数え方

  • 12月31日時点で、手元・倉庫・書店などに委託中の在庫を、品目ごとに数えます。
  • 冬の即売会のように年末ぎりぎりに売った分は、売った後の数で数えます。
  • 保存用・見本誌・無料配布で抜いた分は、在庫に含めません（何部抜いたかメモ）。
  • 前の年から売っている既刊は、去年と同じ1部あたりの原価を使います。

売上の記帳：手数料を引く前の金額で

売り方売上にする金額経費になるもの
BOOTH売れた金額（手数料を引く前）サービス利用料などの手数料 → 支払手数料、発送の送料 → 荷造運賃
pixivFANBOX・Fantia支援額（手数料を引く前）手数料 → 支払手数料
即売会イベントごとの売上合計（何を何部、いくらで）サークル参加費 → 広告宣伝費など、交通費・宿泊費 → 旅費交通費、搬入の送料 → 荷造運賃
書店委託売れた金額（委託手数料を引く前）委託手数料 → 支払手数料

即売会の現金売上は、記録が残りにくいので、イベントが終わったら持って行った数と残った数から、売れた数と金額をメモしておきましょう。

クリエイターがよく使う経費

  • 画材・ペン・紙、10万円未満の液タブ・パソコン周辺機器 → 消耗品費
  • CLIP STUDIO PAINT・Adobe などの月額ソフト → 通信費など（毎年同じ科目に）
  • 資料の本・写真集 → 新聞図書費
  • 背景の外注、アシスタント代 → 外注工賃
  • 自宅の作業部屋の家賃・電気代 → 地代家賃・水道光熱費（家事按分）

何費か迷ったら、勘定科目さがしで調べられます。

ひとり帳簿 Pro なら

売上の記帳で「差し引かれた手数料」を入れると、売上と支払手数料を同時に記帳。年末に品目ごとの原価と在庫数を入れれば、売上原価と決算書の数字を出します。去年の在庫は今年の期首に自動で引き継ぎます。

よくある質問

イベントで配った無料の本やペーパーは？

宣伝のために無料で配った物は、在庫から外し、その製作費は広告宣伝費として扱えます。配った数をメモしておきましょう。

自分用に取っておいた本や見本誌は？

売り物ではなくなった分は、在庫に含めません。保存用・見本誌として何部抜いたかをメモしておくと、在庫数の説明がしやすくなります。

同人活動は事業所得と雑所得のどちら？

活動の規模や継続性などで判断されます。国税庁の解説では、帳簿を記録・保存している場合は事業所得に区分される場合が多いとしています。会社員の副業なら、所得が20万円を超えると確定申告が必要です。
